# Goal-Tracker

A modern, static goal-tracker UI inspired by mobile habit apps with a refreshed teal-indigo theme and useful extras:

- Progress ring with animated completion
- Habit timeline and day/session selectors
- Health snapshot cards and mini calendar
- Streak, consistency, and quick action widgets

## Run locally

Open `/home/runner/work/Goal-Tracker/Goal-Tracker/index.html` in a browser.
