# Goal-Tracker

A customizable goal tracking web app built with vanilla HTML, CSS, and JavaScript.

## Features

- Create, edit, complete, and delete goals
- Set due dates, priorities, categories, and details
- Add your own custom categories
- Track progress with per-goal progress sliders
- Filter by status, category, and priority
- Search goals by title/details
- Sort goals by newest, oldest, due date, priority, or title
- Customize appearance:
  - Light/dark theme
  - Accent color
  - Normal/compact card density
- Local persistence using browser `localStorage`

## Run locally

```bash
npm start
```

Then open `http://localhost:4173`.
